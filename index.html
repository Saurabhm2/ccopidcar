🔥 Firebase Setup

To store up to 15,000 students, configure Firebase:

1. Go to console.firebase.google.com
2. Create a new project
3. Enable Firestore Database and Storage
4. Go to Project Settings → Your apps → Web app → Register
5. Copy the firebaseConfig object
6. Open this HTML file, find const firebaseConfig = { near the top and replace the placeholder values
7. Also enable Authentication (optional, for extra security)
